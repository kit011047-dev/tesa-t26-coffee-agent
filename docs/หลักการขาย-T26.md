# หลักการขายเมล็ดกาแฟของทีม T26 (สำหรับลองกับกฎและ LLM)

เอกสารนี้สรุปว่าตลาดทำงานยังไง agent ของทีมขายด้วยกฎอะไร และทำไม
พร้อม prompt ให้ลองเอากฎชุดเดียวกันไปให้ LLM ตัดสินใจ เพื่อเทียบว่ากฎกับ LLM ต่างกันแค่ไหน

> ⚠️ **กติกาเรื่อง LLM:** ช่วงแข่ง (วันที่ 18 และ 20) ใช้ LLM ได้เฉพาะ **gateway ของงาน** เท่านั้น
> LLM อื่น (ChatGPT, Claude, Gemini, Ollama บนเครื่อง) **ผิดกติกา ตัดสิทธิ์ทั้งการแข่ง**
> การทดลองในเอกสารนี้ให้ทำ **นอกช่วงเก็บคะแนน** หรือในตลาดซ้อมเท่านั้น

## 1. ตลาดทำงานยังไง

### 1.1 มูลค่าจริง (TV) ของล็อต

```
TV (บาท/กก.) = 120 × G × M × S
```

| ตัวคูณ | มาจาก | กฎ |
|---|---|---|
| **G** เกรด | % เมล็ดเสีย d | (1 − d/100) × ตัวคูณขั้น |
| **M** ความชื้น | % ความชื้น m | m ≤ 12.5 → 1 · 12.5–15 → (1 − m/100) ÷ 0.875 − 0.02 × (m − 12.5) · m > 15 → 0.60 |
| **S** ขนาดเมล็ด | screen | 12 → 0.92 · 13 → 0.97 · 14–15 → 1.00 · 16–17 → 1.03 · 18 → 1.06 |

ตัวคูณขั้นของ G:

| เมล็ดเสีย | ชั้น | ตัวคูณ |
|---|---|---|
| ≤ 1% | PREMIUM | 1.08 |
| ≤ 3% | GRADE_1 | 1.04 |
| ≤ 5% | GRADE_2 | 1.00 |
| ≤ 7% | GRADE_3 | 0.96 |
| ≤ 15% | BELOW_STANDARD | 0.85 |
| > 15% | REJECT | 0.60 |

ปัดทศนิยม 2 ตำแหน่ง **ตอนท้ายสุดครั้งเดียว**

**ตัวอย่าง:** เมล็ดเสีย 4.71%, ความชื้น 11.55%, ขนาด 15
→ G = (1 − 0.0471) × 1.00 = 0.9529, M = 1, S = 1 → **TV = 114.35**

ตลาดซ้อมมีสูตรนี้ให้ใน `GET /v1/calendar` (`rules`) **ให้ใช้ค่าจากตลาดเสมอ** เพราะวันแข่งอาจเปลี่ยนตัวเลข

### 1.2 ผู้ซื้อ 3 ประเภท

| ประเภท | สเปก | จ่ายแค่ไหน (จากที่เราเจอจริง) |
|---|---|---|
| **Specialty** | เมล็ดเสีย ≤ 3%, ความชื้น ≤ 12.5%, ขนาด ≥ 16–17 | ยังไม่มีข้อมูล (เพิ่งมีในตลาดวันที่ 18) น่าจะสูงสุด |
| **Commercial** | เมล็ดเสีย ≤ 7%, ความชื้น ≤ 12.5% | ราว **0.99–1.04 × TV** |
| **Instant** | เมล็ดเสีย ≤ 15%, ความชื้น ≤ 14% | ราว **0.92–0.97 × TV** (บางรายต่ำกว่านี้) |

- ผู้ซื้อแต่ละรายมี **เพดานลับ** เป็นตัวคูณ × TV ไม่บอกใคร และ**ต่างกันแม้เป็นประเภทเดียวกัน**
- **ผู้ซื้อตรวจสเปกกับคุณภาพจริง ไม่ใช่ค่าตัวอย่าง** ที่เราเห็น ล็อตที่อยู่ใกล้ขอบเกณฑ์อาจโดนปฏิเสธ

### 1.3 ผู้ซื้อคัดซองยังไง (ซองปิดผนึก ทุกทีมยื่นพร้อมกัน)

1. ตัดซองที่ไม่ผ่านสเปก → `SPEC_MISMATCH`
2. ตัดซองที่ ราคา ÷ TV **เกินเพดานลับ** → `ABOVE_LIMIT`
3. เรียงซองจาก **ราคา ÷ TV ต่ำสุดก่อน**
4. ซื้อไล่ขึ้นไปจนครบจำนวนที่ต้องการ → `ACCEPTED` / `PARTIAL`
5. ซองที่เหลือ (ครบแล้ว) → `OUTBID`

**จ่ายตามราคาที่แต่ละทีมยื่น** และซองที่คุ้มเท่ากันแบ่งกันทีละกระสอบ

### 1.4 คะแนน (เต็ม 100 ต่อเกม)

**ขาย 80 คะแนน**
```
PR = (รายได้ + 0.80 × TV ของที่ขายไม่ออก) ÷ TV รวมทั้งหมด
คะแนนขาย = 80 × (PR − 0.80) ÷ (PR ของทีมที่ดีที่สุด − 0.80)
```
- ขายไม่ออก ระบบขายให้ที่ **0.80 × TV** อัตโนมัติ → ขายต่ำกว่า 0.80 = ขาดทุนเทียบกับไม่ขาย
- คะแนนเทียบกับทีมอื่น: PR ต่างกัน 0.01 อาจต่างกันหลายคะแนน

**ประเมินมูลค่า 20 คะแนน**
- ส่ง TV ของทุกล็อตได้ครั้งเดียวในช่วง APPRAISAL
- คลาด 0% = 20 คะแนน, คลาด 10% ขึ้นไป = 0, **ไม่ส่ง = 0**

### 1.5 กติกาวันที่ 18 (ตลาดซ้อมเปลี่ยนตามแล้ว)
- **ช่วงส่งมูลค่าประเมินแค่ 60 วินาที** → agent ต้องรันไว้ก่อนเกมเริ่ม
- 8 รอบ รอบละ 90 วินาที
- **capacity:** ต่อรอบยื่นรวมได้ไม่เกิน ceil(1.5 × กระสอบทั้งหมด ÷ จำนวนรอบ) กระสอบ (ดู `capacity_left_kg`)
- มีผู้ซื้อ Specialty

## 2. กฎการขายของทีม (สิ่งที่ agent ทำทุกรอบ)

**หลักคิด:** เกมนี้คือการหาราคาที่ **ต่ำกว่าเพดานลับนิดเดียว และถูกกว่าคู่แข่งนิดเดียว**
ไม่มีใครบอกทั้งสองค่า → **ต้องเรียนรู้จากผลแต่ละรอบ แยกผู้ซื้อแต่ละราย**

กฎนี้พัฒนามาจากวิธีที่เราขายด้วยมือในรอบแรก (เริ่มที่ TV แล้วไล่ราคาดูว่าผู้ซื้อรับได้แค่ไหน)

### กฎ 1: คิดราคาเป็น "ตัวคูณ × TV" เสมอ
```
ราคา (บาท/กก.) = ตัวคูณ × TV ของล็อต
```
ผู้ซื้อเทียบกันที่ ราคา ÷ TV ไม่ใช่ราคาดิบ

### กฎ 2: ตัวคูณเริ่มต้น (ผู้ซื้อที่ยังไม่เคยยื่นให้)
| ประเภท | เริ่มที่ |
|---|---|
| Specialty | 1.05 |
| Commercial | 1.00 |
| Instant | 0.92 |

ถ้าเคยยื่นให้ผู้ซื้อ**ประเภทเดียวกัน**รายอื่นแล้ว ใช้ค่าที่เรียนรู้ของประเภทนั้นแทน

### กฎ 3: เรียนรู้แยกผู้ซื้อแต่ละราย (หัวใจของกลยุทธ์)
ดูผลรอบที่แล้วของผู้ซื้อรายนั้น แล้วตั้งตัวคูณรอบนี้:

| ผลรอบที่แล้ว | ตัวคูณรอบนี้ |
|---|---|
| **ขายได้ทุกซอง** (ไม่มีซองที่ราคาสูงกว่าแพ้) | ราคาสูงสุดที่ขายได้ **+ 0.01** |
| ขายได้บางซอง ซองที่ราคาสูงกว่าแพ้ | **คง**ราคาสูงสุดที่ขายได้ |
| **แพ้คู่แข่ง (OUTBID)** ทุกซอง | ราคาต่ำสุดที่แพ้ **− 0.01** และถ้าแพ้ติดกันหลายรอบ ถอยแรงขึ้น −0.02, −0.03 |
| **เกินเพดาน (ABOVE_LIMIT)** ทุกซอง | ราคาต่ำสุดที่เกิน **− 0.03** แต่ไม่ต่ำกว่าราคาที่เคยขายได้ |

และ**ห้ามยื่นถึงราคาที่เคยโดน ABOVE_LIMIT อีก** (ต้องต่ำกว่าอย่างน้อย 0.01)

### กฎ 4: ซองลองราคา
ผู้ซื้อที่รู้จักแล้ว: แบ่ง 1 กระสอบไปยื่นสูงกว่าราคาหลัก **+0.02** (แต่ไม่ชนเพดานที่รู้)
→ เผื่อผู้ซื้อใจป้ำกว่าที่คิด

### กฎ 5: เลือกผู้ซื้อ
- ล็อตที่เข้าสเปก Commercial/Specialty ได้ **ห้ามขาย Instant** จนกว่าจะเหลือ 2 รอบสุดท้าย (Instant จ่ายน้อยกว่า)
- **ล็อตที่โดน SPEC_MISMATCH กับประเภทไหน → เลิกยื่นให้ประเภทนั้น** แล้วปล่อยไปขาย Instant ได้ทันที
- ล็อตที่ไม่เข้าสเปกใครเลย → ไม่ยื่น ปล่อยให้ระบบขาย 0.80

### กฎ 6: กระจายซอง
ล็อตหนึ่งแบ่งยื่นได้ถึง **3 RFQ ต่อรอบ** (ราคาเดียวกัน) ถ้าแพ้ใบที่คู่แข่งเยอะ ใบอื่นยังขายได้

### กฎ 7: แบ่งขายแต่ละรอบ
```
กระสอบที่ยื่นรอบนี้ ≈ 1.6 × (ที่เหลือ ÷ จำนวนรอบที่เหลือ)
```
รอบสุดท้ายยื่นที่เหลือทั้งหมด และไม่เกิน capacity

### กฎ 8: เร่งขายรอบท้าย
| รอบที่เหลือ | ลดตัวคูณเพิ่ม |
|---|---|
| 2 | −0.01 |
| 1 (สุดท้าย) | −0.04 |
| capacity ไม่พอขายหมด | −0.02 เพิ่ม |

### กฎ 9: พื้นราคา
**ไม่ต่ำกว่า 0.85 × TV เด็ดขาด** (ขายไม่ออกยังได้ 0.80 อยู่แล้ว)

## 3. หลักฐานว่ากฎนี้ได้ผล

### ตลาดซ้อมจริง (17 พ.ย. เจอบอทคู่แข่ง 19 ตัวของผู้จัด)
| เกม | PR | อันดับ | หมายเหตุ |
|---|---|---|---|
| agent ตั้งต้นของผู้จัด (1.00 × TV ตายตัว) | – | – | โดนปัดตก 14 ซอง ขายแทบไม่ได้ |
| ขายด้วยมือ (รอบเก็บคะแนน) | ≈ 0.936 | – | |
| กฎของเรา เกม 1 | **0.987** | 🥇 1 | |
| กฎของเรา เกม 2 | 0.925 | 4 | ล็อต REJECT 10 กระสอบ + คู่แข่งตัดราคาแรง |
| กฎของเรา เกม 3 | **0.968** | 🥇 1 | |
| กฎของเรา เกม 4 | 0.948 | 4 | 3 ใน 4 ล็อตขายได้แค่ Instant แต่ขายหมดทุกกระสอบ |

### ตลาดจำลอง (`tools/sim2.py`, 500–800 เกมต่อแบบ)
| | PR เฉลี่ย | คู่แข่งตัดราคาแรง |
|---|---|---|
| ตัวตั้งต้น 1.00 ตายตัว | 0.89 | 0.87 |
| **กฎของเรา** | **0.96** | **0.95** |

### ไอเดียที่ลองแล้ว "ไม่ดีขึ้น" (อย่าเสียเวลาซ้ำ)
- เริ่ม Commercial ต่ำ (0.98) → แย่ลงชัดเจน
- ขยับขึ้นเร็ว (+0.02) หรือช้า (+0.005) → แย่ลงเล็กน้อย
- ไม่ขยับขึ้นถ้ามีซองแพ้ที่ราคาเท่ากัน → แย่ลงเล็กน้อย
- ขั้นบันไดราคาข้ามหลายใบ (ใบแรก 1.00 ใบสอง 0.97 ใบสาม 0.94) → **แย่ลง 0.008** (ขั้นล่างขายได้แต่ถูกเกินไป)
- แบ่งขายตามปฏิทินเทศกาล → ผลไม่ชัด

## 4. ลองกับ LLM

### 4.1 แนวทางการทดลอง
เทียบ 3 แบบในตลาดซ้อม (หรือตลาดจำลอง) แบบละหลายเกม:

| แบบ | LLM ทำอะไร | สิ่งที่ได้เรียนรู้ |
|---|---|---|
| A. กฎล้วน | ไม่ใช้ | ค่าอ้างอิง |
| B. LLM ตัดสินใจเองทั้งหมด | เลือก RFQ, กระสอบ, ตัวคูณ โดยดูแค่ข้อมูลตลาด | LLM เข้าใจหลักการเองได้แค่ไหน |
| C. LLM + กฎในข้อ 2 เป็น prompt | ให้ LLM ทำตามกฎ แต่ปรับได้เมื่อมีเหตุผล | LLM ช่วยหรือทำให้แย่ลง |

**สิ่งที่ต้องวัด:** PR, จำนวนกระสอบที่ค้าง, ตัวคูณเฉลี่ยที่ขายได้แยกตามประเภทผู้ซื้อ, จำนวนครั้งที่ LLM ตอบไม่ทันหรือตอบผิดรูปแบบ

**ข้อควรระวัง**
- รอบมีแค่ **90 วินาที** LLM ต้องตอบให้ทัน (starter ตั้งให้เหลือ 5 วินาทีก่อนรอบปิด ถ้าไม่ทันใช้กฎแทน)
- LLM ตัวเล็กมัก**เสนอน้อยเกินไป** starter มีกฎเติมปริมาณให้อยู่แล้ว
- **ต้องตรวจทุกซองที่ LLM ตอบ** (guard) อย่าเชื่อตัวเลขของ LLM ตรง ๆ
- README ของผู้จัดบอกว่า LLM qwen3.5:9b ใน starter ได้ PR ราว 0.92 (อันดับ 8/20)

### 4.2 ใส่ prompt ตรงไหน
ใน starter kit: `strategy.py` → ตัวแปร `SYSTEM` (คำสั่งระบบ) และฟังก์ชัน `llm_plan()` (ข้อมูลที่ส่งให้ LLM แต่ละรอบ)
เปิดใช้ด้วย `.env`: `USE_LLM=1`, `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`
(ซ้อมด้วย Ollama บนเครื่องได้ **เฉพาะนอกช่วงเก็บคะแนน**: `LLM_BASE_URL=http://localhost:11434/v1`)

### 4.3 System prompt สำหรับแบบ C (คัดลอกไปใช้ได้)

```text
You are the sales agent of a coffee farm selling green robusta in a sealed-offer market.
Each round buyers post RFQs. Choose which candidates (lot x RFQ) to offer, how many 60 kg bags,
and a markup. price = markup x the lot's true value estimate (tv).

How buyers decide: they drop offers that fail the spec (checked on TRUE quality) or whose
price/tv is above their hidden ceiling, sort the rest by price/tv (cheapest first), and buy
until full. Winners are paid their own price. Unsold beans are auto-sold at 0.80 x tv at the end.

Follow these rules unless the recent results clearly say otherwise:
1. Starting markup for a buyer you have not offered to yet: SPECIALTY 1.05, COMMERCIAL 1.00,
   INSTANT 0.92. If you already learned another buyer of the same type, start from that.
2. Learn PER BUYER from last round:
   - all offers sold            -> highest sold markup + 0.01
   - some sold, higher ones lost -> keep the highest sold markup
   - all OUTBID                  -> lowest lost markup - 0.01 (step 0.02, 0.03 if it keeps losing)
   - all ABOVE_LIMIT             -> lowest rejected markup - 0.03, but not below a markup that sold
   Never offer at or above a markup that was ABOVE_LIMIT for that buyer.
3. With 2+ bags for a known buyer, put 1 bag at +0.02 as a probe (still below the known ceiling).
4. Lots that fit COMMERCIAL/SPECIALTY: do not sell them to INSTANT until 2 rounds are left.
   If a lot got SPEC_MISMATCH with a buyer type, stop offering it to that type.
5. Spread one lot over up to 3 RFQs at the same markup.
6. Offer about 1.6 x (bags left / rounds left) this round; everything in the last round.
   Never exceed the round capacity.
7. Rounds left = 2: markup - 0.01. Last round: markup - 0.04.
8. Never go below 0.85.

Answer only JSON matching the schema. Keep "reason" short: which rule you used per buyer.
```

### 4.4 ข้อมูลที่ควรส่งให้ LLM แต่ละรอบ (เพิ่มใน `llm_plan()`)
ตัวตั้งต้นส่งแค่สรุปผล 3 รอบล่าสุดแบบรวม ควรส่งให้ละเอียดขึ้น:
- **ผลรอบก่อนแยกผู้ซื้อ:** `buyer_id, ประเภท, ตัวคูณที่ยื่น, ผล`
- **ตัวคูณที่ "กฎ" คำนวณให้แล้ว** (จาก `learn()` ใน `strategy.py`) → ให้ LLM เห็นคำตอบของกฎแล้วตัดสินว่าจะเห็นด้วยหรือปรับ
- **รอบที่เหลือ** และ **capacity ที่เหลือ** (`capacity_left_kg`)
- **ภาพรวมตลาด** (`market_summary`): แต่ละ RFQ ต้องการกี่กระสอบ ซื้อได้กี่กระสอบ กี่ซอง ช่วงราคาที่ขายได้

### 4.5 คำถามที่การทดลองนี้ช่วยตอบ
- LLM เข้าใจไหมว่า**ขายต่ำกว่า 0.80 แย่กว่าไม่ขาย**
- LLM แยกได้ไหมว่า **OUTBID (แพ้คู่แข่ง) กับ ABOVE_LIMIT (เกินเพดาน)** ต้องตอบสนองต่างกัน
- LLM ใช้ภาพรวมตลาด (RFQ ไหนคู่แข่งน้อย) ได้ดีกว่ากฎไหม ซึ่งกฎของเรายังไม่ได้ใช้
- ในรอบท้าย LLM กล้าเทขายพอไหม หรือกั๊กไว้จนค้าง
