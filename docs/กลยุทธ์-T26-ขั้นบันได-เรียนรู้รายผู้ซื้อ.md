# กลยุทธ์ T26: ขั้นบันได + เรียนรู้รายผู้ซื้อ

กลยุทธ์ขายเมล็ดกาแฟของ agent ทีม T26 (TESA Top Gun Rally 2026 · Track 3 The Next-Gen Market)
โค้ดอยู่ที่ `~/tesa-starter/strategy.py` (ส่วนที่ขึ้นต้นด้วย `[T26]`) ทำงานด้วยกฎล้วน **ไม่ใช้ LLM**

## 1. แนวคิดในหนึ่งย่อหน้า

ผู้ซื้อแต่ละรายมี **เพดานราคาลับ** (ตัวคูณ × TV ที่ยอมจ่ายสูงสุด) และมี **คู่แข่ง** มายื่นแย่งกัน
ไม่มีใครบอกทั้งสองค่า ราคาที่ดีที่สุดคือราคาที่ **ต่ำกว่าเพดานนิดเดียว และถูกกว่าคู่แข่งนิดเดียว**
agent จึงเริ่มจากราคาที่พอเดาได้ แล้ว **ใช้ผลของแต่ละรอบเป็นข้อมูล** ขยับราคาขึ้นหรือลง
**แยกเป็นรายผู้ซื้อ** เพราะผู้ซื้อประเภทเดียวกันยังจ่ายไม่เท่ากัน (เจอจริง: Instant B5 รับ 0.97 แต่ B6 ไม่รับ)

ที่มา: พัฒนาจากวิธีที่ทีมขายด้วยมือในรอบเก็บคะแนนวันที่ 17 พ.ย. (เริ่มที่ TV แล้วไล่ราคาดูว่าผู้ซื้อรับได้แค่ไหน)
แล้วแปลงเป็นโค้ดให้ทำเร็วกว่า จำแม่นกว่า และขยับได้ทั้งขึ้นและลง

|---|---|---|
| ① | หาคู่ (ล็อต × RFQ) ที่ค่าตัวอย่างผ่านสเปก · ตัดคู่ที่เคยโดน SPEC_MISMATCH · ล็อตที่เข้า Commercial/Specialty ได้ไม่ขาย Instant จนเหลือ 2 รอบ | `candidates()`, `spec_failed()` |

## 3. กฎการเรียนรู้ (หัวใจของกลยุทธ์)

ทุกรอบ agent ไล่ดูซองที่ยื่นไปในแต่ละรอบที่ผ่านมา แยกตามผู้ซื้อ แล้วตั้งตัวคูณรอบหน้าดังนี้

| ผลของผู้ซื้อรายนั้นในรอบนั้น | ตัวคูณรอบหน้า | เหตุผล |
|---|---|---|
| **ขายได้ทุกซอง** (ไม่มีซองที่ราคาสูงกว่าแพ้) | สูงสุดที่ขายได้ **+0.01** | ยังมีที่ว่างข้างบน ลองดันขึ้น |
| ขายได้บางซอง แต่ซองที่ราคาสูงกว่าแพ้ | **คง**สูงสุดที่ขายได้ | เจอขอบตลาดแล้ว |
| **แพ้คู่แข่งทุกซอง** (OUTBID) | ต่ำสุดที่แพ้ **−0.01 × จำนวนรอบที่แพ้ติดกัน** (สูงสุด −0.03) | ใกล้แล้ว แค่แพ้ราคา ถ้าแพ้ซ้ำแปลว่าตลาดลงจริง ถอยแรงขึ้น |
| **เกินเพดาน** ทุกซอง (ABOVE_LIMIT) | ต่ำสุดที่เกิน **−0.03** แต่ไม่ต่ำกว่าราคาที่เคยขายได้ | เกินเพดานลับ ต้องลดมากกว่า |
| ไม่ผ่านสเปก (SPEC_MISMATCH) | เลิกยื่นคู่ (ล็อต, ประเภทผู้ซื้อ) นั้น | ค่าจริงไม่ผ่าน ยื่นอีกก็ไม่ได้ |

**กฎเหล็กเรื่องเพดาน:** ทุกครั้งที่โดน ABOVE_LIMIT จะจำ "เพดานที่รู้แล้ว"
และ **ตัวคูณที่จะยื่นต้องต่ำกว่าเพดานนั้นอย่างน้อย 0.01 เสมอ** (รวมถึงซองลองราคาด้วย)

**รหัสเทียม (`learn()`)**
```
สำหรับแต่ละรอบที่ผ่านมา:
    สำหรับแต่ละผู้ซื้อ (และแต่ละประเภทผู้ซื้อ):
        sold = ตัวคูณที่ขายได้, lost = ที่ OUTBID, over = ที่ ABOVE_LIMIT
        ถ้ามี over:  ceil = min(ceil, min(over))
        ถ้ามี sold:  streak = 0
                     m = max(sold) + 0.01   ถ้า max(sold) คือราคาสูงสุดที่ยื่น
                         max(sold)          ถ้ามีซองราคาสูงกว่าที่ไม่ได้
        หรือถ้ามี lost: streak += 1;  m = min(lost) − min(0.01 × streak, 0.03)
        หรือถ้ามี over: m = min(over) − 0.03 (ไม่ต่ำกว่าราคาที่เคยขายได้)
        m = min(m, ceil − 0.01)
```

## 7. ข้อจำกัดที่รู้อยู่

- **ไม่ใช้ภาพรวมตลาด** (RFQ ไหนคู่แข่งน้อย ราคาที่ทีมอื่นขายได้) แม้ตลาดจะให้มา เพราะตลาดจำลองยังวัดผลส่วนนี้ไม่ได้
- **Specialty ยังไม่เคยเจอจริง:** เริ่มที่ 1.05 แล้วเรียนรู้เอง ถ้าเพดานจริงต่ำกว่านี้มาก จะเสีย 1–2 รอบแรก
- **รอบแรกเป็นการหยั่ง:** ผู้ซื้อที่ใจป้ำมาก (เพดาน 1.07) จะได้ราคาต่ำกว่าที่ควรไปบ้าง เพราะขยับขึ้นทีละ 0.01
- **ล็อตเล็ก** (ใบละ 1 กระสอบ) จะไม่มีขั้นบันไดในใบเดียว ใช้ราคาเดียวแล้วเรียนรู้จากหลายใบแทน
- **ตลาดจำลองเป็นแบบจำลอง** ตั้งค่าจากข้อมูลตลาดซ้อม 5 เกม ตลาดจริงที่มี 56 ทีมอาจแข่งแรงกว่า แต่ agent ปรับตามผลจริงอยู่แล้ว

## 8. วิธีทดลองหรือปรับต่อ

```bash
cd ~/tesa-starter
.venv/bin/python tools/sim2.py              # เทียบกลยุทธ์หลายแบบในตลาดจำลอง
.venv/bin/python tools/report.py            # สรุปเกมที่กำลังเล่น: ซองที่ยื่น ตัวคูณ ผล สิ่งที่เรียนรู้
```

- เปลี่ยนค่าใน `strategy.py` ส่วน `[T26]` แล้วรัน `sim2.py` เทียบก่อนทุกครั้ง **ดีขึ้นจริงถึงค่อยใช้**
- ทดลองค่าโดยไม่แก้ไฟล์: `sim2.evaluate({"PACE": 2.0}, range(500), rounds=8, cap=1.5)`
- ผลดิบของทุกเกมอยู่ใน `logs/memory-*.json` (ซองที่ยื่น + ผลจากตลาด + ภาพรวมตลาดทุกรอบ)
- **ห้ามแก้โค้ดระหว่างรอบเก็บคะแนน**
