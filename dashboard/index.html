รับรู้: ข้อมูลที่เห็นรอบนี้

      
ดึงจาก /v1/state: ล็อตของเรา (ค่าตัวอย่าง) + RFQ ของผู้ซื้อแต่ละรายรอบนี้
ยังไม่มีข้อมูล

    
เซนเซอร์ Pi: Track 1 ความชื้น + Track 2 YOLO นับเมล็ด

      
ค่าจาก Raspberry Pi เทียบกับตัวอย่างที่ตลาดให้ · แสดงอย่างเดียว ไม่ใช้ตั้งราคา (ราคาและ TV มาจากตัวอย่างของตลาดเท่านั้น)

      
ยังไม่มีข้อมูล (เปิดด้วย PI_ENABLED=1 ใน .env)

    
เข้าใจ: ประเมินมูลค่า + ขายให้ใครได้

      
TV = 120 × G × M × S ต่อ กก. แล้วเช็กสเปกผู้ซื้อแต่ละราย (ชี้ชื่อที่ขีดฆ่าเพื่อดูเหตุผล)
ยังไม่มีข้อมูล

    
ตัดสินใจ: ข้อเสนอที่เลือก

      
ราคา = ตัวคูณที่เรียนรู้ × TV · ล็อตละได้ถึง 3 RFQ · ผู้ซื้อใหม่เริ่ม Commercial 1.00 / Instant 0.92 · ขั้นต่ำ 0.85 × TV
ยังไม่มีข้อมูล

    
LLM รายรอบ: LLM เห็นอะไร ตอบอะไร ใช้จริงแค่ไหน

      
เทียบตัวคูณที่ LLM เลือกกับที่กฎ T26 แนะนำ · ส้ม = LLM ตั้งสูงกว่ากฎ · น้ำเงิน = ต่ำกว่า · ใช้ปรับ temperature / prompt

      
ยังไม่มีข้อมูล (โหมดกฎล้วนไม่เรียก LLM)

    
ลงมือ: ส่งข้อเสนอ

      
POST /v1/offers:batch (ทั้งชุดในครั้งเดียว ถ้าถูกปฏิเสธส่งทีละซอง)
ยังไม่มีข้อมูล

    
กำกับดูแล: กฎความปลอดภัย

      
ตรวจทุกซองก่อนส่ง: สเปก · ≥ 0.85 × TV · ทวีคูณ 60 กก. · ไม่เกิน RFQ / ล็อตเหลือ / capacity
ยังไม่มีข้อมูล

    
เรียนรู้: ผลรอบนี้ + สิ่งที่รู้เกี่ยวกับผู้ซื้อ

      
ขายได้ → ขยับขึ้น · แพ้คู่แข่ง → ถอย (แพ้ติดกันยิ่งถอยแรง) · เกินเพดาน → ลด และไม่ยื่นชนเพดานเดิมอีก
ยังไม่มีข้อมูล

    
หลายเอเจนต์: ภาพรวมตลาด (ทุกทีม)

      
ตลาดไม่บอกว่าทีมไหนขายอะไร มีแต่ภาพรวมต่อ RFQ: ต้องการ / ซื้อได้ / กี่ซอง / ช่วงราคาที่ขายได้
ยังไม่มีข้อมูล
