# ส่วนที่ 9: หน้าต่างดูการทำงานของ agent (Dashboard)

แสดงสดว่า agent กำลังทำอะไร แบ่งเป็น 7 ความสามารถ ขั้นไหนกำลังทำงานจะเรืองแสง

| ขั้น | ดูอะไรได้ |
|---|---|
| รับรู้ (Perception) | ล็อตที่เหลือ, ผู้ซื้อ, เกณฑ์, งบเหลือ, ข้อมูลมาจาก server หรือ Raspberry Pi |
| เข้าใจ (Understanding) | มูลค่าที่ประเมินต่อ กก. + ขายให้ใครได้ / ไม่ได้เพราะอะไร |
| ตัดสินใจ (Decision) | ข้อเสนอ ราคา โอกาสขายได้ ราคาขั้นต่ำ เวลาที่ใช้คิด |
| ลงมือ (Action) | ส่งข้อเสนอสำเร็จ/ล้มเหลว |
| เรียนรู้ (Learning) | ผลแต่ละรอบ, รายได้ต่อรอบ, r50 ของผู้ซื้อ (ค่าเดาเริ่มต้นเทียบกับที่เรียนรู้) |
| หลายเอเจนต์ (Multi-Agent) | ทีมคู่แข่งขายอะไร ราคาเท่าไร |
| กำกับดูแล (Governance) | ตรวจทุกข้อเสนอก่อนส่ง: ผู้ซื้อรับเกรดได้, ราคา ≥ ขั้นต่ำ, ไม่เกินงบ + สถานะ Pi / retry |

## ซ้อม (คำสั่งเดียว)
```bash
python -m part9.run_demo                 # เปิดตลาดจำลอง + dashboard + agent (หน่วง 2 วิ/รอบ)
python -m part9.run_demo --seed 7 --delay 3
```

## วันแข่ง
```bash
python -m part9.dashboard                # Terminal 1: เปิดหน้าต่าง http://127.0.0.1:8050
python part3/agent.py                    # Terminal 2: agent ตามปกติ (ไม่หน่วง)
```
- ให้เพื่อนในวงแลนดูด้วย: `python -m part9.dashboard --host 0.0.0.0` แล้วเปิด `http://<IP Mac>:8050`
- ไม่ต้องใช้อินเทอร์เน็ต (Python standard library + HTML ไฟล์เดียว)
- dashboard ปิดหรือพัง agent ยังทำงานปกติ (บันทึกห่อ try/except ทุกจุด)

## บั๊กที่ dashboard จับได้ตั้งแต่วันแรก
ช่องกำกับดูแลขึ้น "ผิดกฎ: ไม่เกินงบผู้ซื้อ" รอบ 4–6 ของ seed 42:
งบ R2 เหลือ 116,969 บาท / 1,300 กก. = 89.976 บาท/กก. แต่ `round()` ปัดเป็น 89.98 → รวม 116,974 เกินงบ 5 บาท → โดนปฏิเสธ 3 รอบ
แก้เป็นปัดลง (`floor_price` ใน part6/strategy.py และ baseline ใน agent.py)

| or_full บน seed ทดสอบ 101–130 | ก่อนแก้ | หลังแก้ |
|---|---|---|
| คะแนนเฉลี่ย | 101.27 ± 1.93 | **101.98 ± 0.96** |
| เกมแย่สุด | 76.16 | **98.14** |
| ชนะ baseline | +1.50 ± 1.43 | **+2.20 ± 0.73** |
